# CUAN PARTY V1

Android-first Flutter starter for CUAN PARTY.

## Current
- Splash screen
- Home
- Bottom navigation
- Room list
- Basic room screen
- Dark / gold visual direction

## Run
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Connect an Android device/emulator.
4. Run `flutter run`.

This is a UI foundation only. Authentication, backend, realtime voice, wallet, gifts, and admin services are intentionally next phases.
